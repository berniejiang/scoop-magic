Scoop bucket for Personal.

## Usage

1. Install [scoop](https://github.com/lukesampson/scoop)

2. Add this bucket to scoop:
```bash
scoop bucket add magic https://github.com/berniejiang/scoop-magic.git
```
3. Install tools via `scoop install`:
```bash
scoop install xxx
```
4. Done.
